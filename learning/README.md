# Learning to Build Riley

This folder is our running programming notebook. We learn as we build, using real Riley code, with optional challenges in safe practice files.

## Our agreement
- Build and test small features; explain important concepts in plain language.
- Keep Riley's working behavior intact. Never use live permissions or personal files for practice.
- Challenges are optional and do not block development.
- Document each new concept, the file where it appears, and why it matters.
