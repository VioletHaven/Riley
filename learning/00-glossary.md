# Riley programming glossary

- **Variable:** A name that stores a value, such as `permission = "ask"`.
- **Condition:** A true-or-false test that decides which code runs.
- **`if` / `elif` / `else`:** Python branches that choose between outcomes.
- **Function:** A named reusable block of code, defined with `def`.
- **Argument:** A value supplied to a function.
- **Return value:** A result a function sends back using `return`.
- **Module:** A Python file containing code that other files can import.
- **Test:** Code that checks whether behavior matches expectations.
- **Allowlist:** A specific set of permitted actions or targets.
- **Deny by default:** If permission is unknown or missing, reject the action.
- **Scope:** The specific folder, action, or target a permission covers.
- **Audit log:** A record of attempted and completed actions.
